OCR Gateway Configuration
=========================

Environment variables
---------------------
- OCR_PROVIDER: Provider selector (`ollama` or `vps`).
- OLLAMA_OCR_ENDPOINT: Full HTTP endpoint for local Ollama OCR API.
- VPS_OCR_ENDPOINT: Full HTTP endpoint for remote GPU VPS OCR API.
- OCR_HTTP_TIMEOUT: Upstream provider timeout in seconds.
- CORS_ALLOW_ORIGINS: Comma-separated frontend origins.

Installation
------------
1) cd server
2) python -m venv .venv
3) source .venv/bin/activate
4) pip install -r requirements.txt
5) cp .env.example .env and edit values
6) export $(grep -v '^#' .env | xargs)
7) uvicorn server:app --host 0.0.0.0 --port 8080

Deployment profile: Local Ollama
--------------------------------
- Set OCR_PROVIDER=ollama
- Ensure local Ollama OCR HTTP endpoint is running.
- Set OLLAMA_OCR_ENDPOINT (default: http://localhost:11434/api/ocr)

Deployment profile: Remote GPU VPS
----------------------------------
- Set OCR_PROVIDER=vps
- Deploy OCR inference service on VPS with an HTTP /ocr endpoint.
- Set VPS_OCR_ENDPOINT to the VPS URL.
- Open inbound network path from gateway host to VPS service.
- Consider TLS termination and firewall allowlist rules in production.

Runtime metrics logging
-----------------------
- Gateway app writes request metrics to: logs/metrics.jsonl
- One JSON object per line: timestamp, provider, success/failure, latency, and request metadata.
- These logs can feed evaluation dashboards and human-in-the-loop training pipelines.
