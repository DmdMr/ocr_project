# Система цифрового архивирования технологических карточек

Информационная система для цифровизации, хранения и поиска технологической документации предприятия.

Приложение позволяет загружать документы и изображения, хранить их в электронном архиве, выполнять полнотекстовый поиск по содержимому, использовать теги и пользовательские поля, управлять доступом пользователей через систему ролей, а также выполнять OCR-распознавание текста на документах.

Проект разработан в рамках выпускной квалификационной работы на тему:

**«Разработка системы цифрового архивирования нормировочных карточек с исследованием OCR-подходов»**

---

# Основные возможности

* Авторизация и аутентификация пользователей.
* Ролевая модель доступа.
* Загрузка документов и изображений.
* Поддержка нескольких изображений для одного документа.
* Просмотр и редактирование документов.
* Система тегирования.
* Пользовательские поля.
* Полнотекстовый поиск.
* OCR-распознавание текста.
* Хранение результатов OCR.
* Архивирование документов.
* Экспорт и импорт данных.
* Настольное приложение на Electron.

# Требования

Перед запуском проекта необходимо установить:

* Python 3.10 или новее
* Node.js LTS
* npm
* Git (опционально)
* Ollama (для работы OCR)

---

# Установка проекта

## Клонирование репозитория

```bash
git clone https://github.com/DmdMr/ocr_project.git
cd ocr_project
```

---

# Настройка Python

## Windows

Создание виртуального окружения:

```bash
python -m venv venv
venv\Scripts\activate
```

## macOS / Linux

Создание виртуального окружения:

```bash
python3 -m venv venv
source venv/bin/activate
```

## Установка зависимостей

```bash
pip install -r backend/requirements.txt
```

---

# Установка зависимостей Frontend

Из корня проекта:

```bash
npm install
```

Если frontend вынесен в отдельную папку:

```bash
cd frontend
npm install
```

---

# Запуск Backend

## Windows

```bash
venv\Scripts\python -m uvicorn backend.app.main:app --host 0.0.0.0 --port 8000
```

## macOS / Linux

```bash
./venv/bin/python -m uvicorn backend.app.main:app --host 0.0.0.0 --port 8000
```

После запуска сервер будет доступен по адресу:

```text
http://localhost:8000
```

---

# Swagger API

Документация API доступна по адресу:

# Запуск Frontend

# OCR-модуль

Для работы OCR необходимо установить Ollama и загрузить используемую модель.

Пример загрузки модели:

```bash
ollama pull qwen3-vl:latest
```

После запуска Ollama модель становится доступной для распознавания документов через интерфейс приложения.

# База данных

Для хранения данных используется SQLite.

Файл базы данных создаётся автоматически при первом запуске приложения.

Пример расположения:

```text
backend/app/data/ocr.db
```

В базе данных хранятся:

* пользователи;
* документы;
* изображения;
* теги;
* пользовательские поля;
* результаты OCR;
* настройки системы.

# Назначение системы

Система предназначена для цифровизации бумажного архива технологической документации предприятия.

Использование системы позволяет:

* сократить время поиска документов;
* централизованно хранить архивные материалы;
* снизить объём ручной обработки данных;
* использовать OCR для извлечения информации из документов;
* создать основу для дальнейшей автоматизации документооборота предприятия.
